Medicaid Policy Search Agent

AI agent that indexes 1,800+ pages of policy to deliver citation-backed answers in under 30 seconds.

10–20 min → 30 sec · Policy search time1,800+ pages indexed

Problem: PA clinicians were spending 10–20 minutes manually searching a 1,800+ page policy corpus for a single clarification, risking missed details and inconsistent decisions.

What I built: A Microsoft Copilot RAG agent that indexes the policy corpus and returns concise answers with source and page citations.

Source & page citations Risk flags

Reviewers retained responsibility for the final interpretation and clinical decision.

Result: The tool reduced a routine 10–20 minute lookup to under 30 seconds while keeping citations and risk flags visible to the reviewer. This public account uses aggregate outcomes only; it contains no policy excerpts, production data, or employer-system screenshots.

Full-Stack / Algorithm

Operations Dashboard + Planner

Flask dashboard with real-time inventory visibility and a greedy qualification-based algorithm that supports daily staffing assignments and saves each supervisor 15–20 minutes a day.

15–20 min saved · Daily planning per supervisor

Problem: Daily staffing assignments were done by gut feel without a transparent view of inventory and staff qualifications.

What I built: A Flask web app with two modules:

Live inventory dashboard Greedy allocation algorithm Staff qualification matrix

The planner generates proposed assignments using due dates, staff qualifications, and remaining volume as explicit criteria.

Result: The planner saved each supervisor 15–20 minutes a day and supported staffing for a 45+ person operation processing 15,000+ cases monthly. Its recommendations stayed inspectable: supervisors could see the due dates, qualifications, and remaining volume behind each assignment.

PA Processing Automation

Desktop tool that automated repetitive PA data entry and raised throughput from 5 to 25 cases per hour.

5x throughput · 5/hr → 25/hr

Problem: Manual data entry (unit calculations, comments, navigation) bottlenecked PA processing to 5 cases per hour, absorbing ~12 minutes per case.

What I built: A Python desktop application using PySimpleGUI that standardizes repetitive calculations, comments, and system interactions while keeping the clinician responsible for the authorization decision.

Auto-calculation of units Standardized comment generation Automated keystroke orchestration

Security & Compliance: Operated strictly client-side to drive UI interactions without saving, logging, or transmitting any PHI to external servers.

Result: I built this as an individual contributor and increased my own throughput from 5 to 25 authorizations per hour. The clinician still made every authorization decision.
